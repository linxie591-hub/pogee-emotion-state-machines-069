Emotion State Machines

Emotion is not a label you attach to a reply. It is a state that persists.

A simple state machine - calm, curious, hurt, delighted - that transitions based on events gives a character an inner life that survives the end of a session.

The value is not realism for its own sake; it is that consistent emotional reactions make the character predictable in a good way.

State, not sentiment analysis, is what makes emotion feel real.
